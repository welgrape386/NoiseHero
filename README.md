# 층간히어로 (NoiseHero) 🏠🔊

> 측정부터 민원서 자동 생성까지 — 원스톱 층간소음 해결 서비스

층간히어로는 층간소음 문제를 단순히 기록하는 데서 끝내지 않고,  
**실시간 소음 측정 → AI 소음 유형 분류 → 법적 기준 비교 → 민원서/PDF 자동 생성**까지 한 번에 지원하는 서비스입니다.

층간소음은 객관적 증거가 부족하면 “시끄럽다”와 “안 그랬다”의 감정싸움으로 번지기 쉽습니다.  
층간히어로는 사용자가 측정 데이터를 기반으로 소음 유형과 기준 초과 여부를 확인하고, 이웃사이센터·분쟁조정위원회 등 제출 목적에 맞는 PDF 문서를 생성할 수 있도록 돕습니다.


---

## ✨ 주요 기능

- **마이크 보정**
  - 측정 시작 전 15초간 배경소음을 측정
  - 기기별 기준값을 설정해 무음 구간 판단에 활용
  - 법적 기준 비교는 보정값이 아닌 원본 측정값 기준으로 수행

- **실시간 소음 측정**
  - 실시간 데시벨 그래프 제공
  - Leq 등가소음도, Lmax 최고소음도 측정
  - 직접충격음·공기전달음 기준 자동 적용
  - 측정 이력 자동 저장

- **AI 소음 유형 분류**
  - SVM 모델 기반 소음 유형 분류
  - 직접충격음과 공기전달음 자동 구분
  - 주요 소음원과 부소음원 판단
  - 분류 결과와 신뢰도 제공

- **민원서/PDF 자동 생성**
  - 측정 데이터를 기반으로 공식 서류 양식 자동 작성
  - 이웃사이센터용 PDF 생성
  - 분쟁조정위원회용 PDF 생성
  - 공식 제출서류 5페이지 PDF 생성
  - 버튼 한 번으로 PDF 다운로드 가능

- **AI 법률 챗봇**
  - GPT 기반 층간소음 상담 챗봇
  - 이웃사이센터 신청 방법 안내
  - 분쟁조정 절차 안내
  - 층간소음 법적 기준 안내
  - 자주 묻는 질문 원터치 버튼 제공

- **상담기관 안내**
  - 이웃사이센터
  - 환경분쟁조정위원회
  - 법률구조공단
  - 공식 기관 연락처 및 안내 정보 제공

- **마이페이지**
  - 프로필 정보 수정
  - 아파트 정보 수정
  - 마이크 보정 재측정
  - 과거 측정 이력 조회

## 🧩 서비스 흐름

```text
[1] 마이크 보정
    → 15초 배경소음 측정
    → 기기별 기준값 저장

[2] 실시간 소음 측정
    → Leq / Lmax 측정
    → 법적 기준 초과 여부 확인

[3] AI 소음 유형 분류
    → SVM 모델로 직접충격음 / 공기전달음 분류
    → 주소음원, 부소음원 판단

[4] 민원서/PDF 자동 생성
    → 측정 이력 선택
    → 제출 목적 선택
    → 공식 PDF 생성 및 다운로드
```

## 🎙 소음 측정 및 AI 분류

층간히어로는 사용자가 녹음한 소음을 기반으로 실시간 측정값과 AI 분류 결과를 제공합니다.

### 측정 항목

| 항목 | 설명 |
|---|---|
| Leq | 등가소음도 |
| Lmax | 최고소음도 |
| 시간대 | 주간 / 야간 |
| 소음 유형 | 직접충격음 / 공기전달음 |
| 주소음원 | 가장 주요한 소음원 |
| 부소음원 | 함께 감지된 보조 소음원 |
| 기준 초과 여부 | 법적 기준 대비 초과 여부 |

### AI 분류

SVM 모델은 녹음된 오디오에서 MFCC, RMS, ZCR 등 음향 특징을 추출해  
소음 유형을 직접충격음과 공기전달음으로 분류합니다.

```text
직접충격음 예시:
- 발소리
- 뛰는 소리
- 문 닫는 소리
- 가구 끄는 소리

공기전달음 예시:
- TV 소리
- 음악 소리
- 대화 소리
- 악기 소리
```

- 소음·진동관리법 제21조의2

## 📄 민원서/PDF 자동 생성

층간히어로는 사용자의 측정 이력과 피해 내용을 기반으로 제출 목적에 맞는 PDF 문서를 생성합니다.

### PDF 생성 API

```http
POST /report/pdf
Content-Type: application/json
```

### PDF 유형

PDF는 `report_type` 값에 따라 생성됩니다.

| report_type | 생성 PDF | 설명 |
|---|---|---|
| `neighbor_center` | 이웃사이센터용 PDF | 층간소음 이웃사이센터 상담·접수용 |
| `dispute_committee` | 분쟁조정위원회용 PDF | 공동주택관리 분쟁조정위원회 제출용 |
| `official_required_forms` | 공식 제출서류 PDF | 방문상담·소음측정 신청에 필요한 공식 양식 5페이지 |

---

## 📄 공식 제출서류 PDF 구성

`official_required_forms` 타입은 총 5페이지로 구성됩니다.

| 페이지 | 서류명 | 설명 |
|---|---|---|
| 1페이지 | 층간소음 방문상담 신청서 | 방문상담 신청을 위한 기본 신청서 |
| 2페이지 | 층간소음 중재상담 보고서 | 관리주체 또는 중재주체의 상담 내용 기록 |
| 3페이지 | 동의서 | 개인정보 수집·이용 및 서비스 진행 동의 |
| 4페이지 | 층간소음 측정 신청서 | 소음측정 신청을 위한 공식 신청서 |
| 5페이지 | 층간소음 발생일지 | 소음 발생일시, 유형, 지속시간 기록 |

공식 서류에서 사용자가 직접 작성해야 하는 성명, 서명, 동의 여부 등은 공란으로 두고,  
앱에서 확인 가능한 정보만 자동 입력되도록 구성했습니다.

## 🧱 시스템 아키텍처

```text
Frontend
React · TypeScript · Vite · Tailwind CSS
        ↓
Backend API
FastAPI · REST API · Render
        ↓
AI / ML
SVM 소음 분류 모델 · GPT API · RAG
        ↓
Database
MongoDB · 사용자 정보 · 측정 이력 저장
```

### 처리 흐름

```text
1. 사용자가 앱에서 소음을 녹음
2. Frontend가 오디오 파일과 요청을 Backend로 전송
3. Backend가 SVM 분류 모델을 호출해 소음 유형과 법적 기준 초과 여부를 판정
4. 판정 결과와 측정값을 MongoDB에 저장
5. 저장된 이력을 기반으로 민원서와 PDF 생성
6. 챗봇 질의는 GPT API + RAG를 통해 근거 기반 응답 제공
```
